## What it does

`main.py` writes a single fortune line for a houseplant to `/output/entry.txt`:

> This week, the sun will visit your windowsill, admire your newest leaf, and stay a little longer just for you.

The line is 110 characters: kind, a little funny, and written for the plant on the windowsill — a prediction, not a care instruction.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3.13. The program writes exactly one line of UTF-8 text and nothing else.
